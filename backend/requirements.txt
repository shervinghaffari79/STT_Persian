# torch + transformers below also cover this -- accelerate speeds up GPU loading
accelerate
# 8-bit chat weights (CHAT_8BIT, on by default on CUDA). Without this the chat
# model loads in fp16 (~8GB instead of ~5GB) and a 16GB card cannot hold
# Whisper + pyannote + chat at once. chat.py logs "[chat] 8-bit requested but
# unavailable" and falls back to fp16 rather than failing, so a missing
# bitsandbytes shows up as an OOM later rather than an install error here.
bitsandbytes
# Windows/Linux run Qwen/Qwen3.5-4B (see backend/chat.py), whose "qwen3_5"
# model_type may not exist yet in a stable transformers release -- its own
# model card says to install from `main`. `>=4.37` is NOT sufficient for it;
# that floor is only what the Qwen2 tokenizer needs. If pip resolves a
# transformers that doesn't recognize qwen3_5, chat.py's _ensure() raises a
# clear, actionable error rather than a bare "Unrecognized configuration
# class" -- but the real fix, if that fires, is:
#   pip install "transformers[serving] @ git+https://github.com/huggingface/transformers.git@main"
# (do NOT let NeMo pin transformers back down to 4.33)
transformers>=4.37
torchvision          # Qwen3.5 is a vision-language checkpoint; its model card
pillow               # requires both even for text-only use
